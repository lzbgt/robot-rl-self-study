# Robot-Safety and Security Reports

For an ordinary documentation or example-code issue, open a GitHub issue.

If a finding could cause unsafe physical-robot behavior, exposes a credential,
or reveals a privately exploitable deployment weakness, do not include the
sensitive details in a public issue. Use GitHub's private vulnerability
reporting feature when it is enabled for this repository, or contact the
repository owner through the private contact mechanism shown on their GitHub
profile.

The examples in this book are educational. They are not a certified safety
controller and do not authorize deployment on physical hardware.
